# MoveKind Park Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the home screen with a full-screen, horizontally panning park whose objects are how you log, plus a pull-up drawer, then add sleep (hammock), a rabbit, and ambient sound, in four owner-tested stages.

**Architecture:** A pure layout module places every park object in world units across a panorama 2.2 screens wide; the foreground scrolls in a horizontal `ScrollView` and the sky and hill layers are translated from its scroll offset (Animated, native driver) for parallax. Tappable objects are accessible hotspot buttons laid over the drawing. All "what the park shows" stays in pure domain functions (`gardenState` plus new `parkLayout`, `untendedToday`, `rabbitMood`); stores own data; sheets and the drawer are thin components.

**Tech Stack:** Expo SDK 58 (Expo Go), React Native 0.88 `Animated` + `ScrollView`, react-native-svg, Zustand, AsyncStorage via `src/services/db`, expo-audio (stage 4), Jest + Testing Library 13.

**Spec:** `docs/superpowers/specs/2026-10-27-park-design.md`

## Global Constraints

- Portrait only; the park pans horizontally; world width = 2.2 × screen width.
- Style: flat shapes, no outlines, vertical gradients, drifting mist between hill layers, sage palette (reference `design/park/gemini-park-times-of-day.jpg`).
- Tapping a park object always opens a small sheet; no accidental logs.
- Almost no text on the park: one soft greeting that fades after a few seconds.
- Never decay, dryness, hunger, sadness or "X of N": stream/grass floors, tree never shrinks, rabbit never sad/hungry/sick, no fixed empty slots.
- Common logs take at most two taps.
- No typing anywhere new; no permission prompts at launch; sound off by default.
- Every object reachable and labelled for screen readers; Reduce Motion stops drift, parallax easing and creature motion.
- Expo Go compatible (no native modules outside Expo Go); all colour from tokens; contrast pairs tested; no em dashes; Plus Jakarta Sans via `...font.*`.
- Local-first: sleep stored on device; telemetry sends `logged {kind}` only, never values.
- Verify every task with `npm run typecheck` and `npm test`.

## Review Focus

1. **Small and very wide screens:** world layout must keep every hotspot on-screen-reachable and ≥44pt at 320pt and 430pt widths. → test in Task 1 (`hotspots stay at least 44pt on small and large phones`).
2. **Panning while a sheet is open / tapping during momentum scroll:** a tap must open exactly one sheet. → test in Task 5 (`only one sheet opens at a time`: open the river, then tap the tree ⇒ water closed, workout open).
3. **Day rollover:** shimmer and sleep "today" use local days; a sleep logged at 00:30 belongs to that morning. → tests in Task 2 (`untended resets at local midnight`) and Task 7 (`sleep logged just after midnight counts for that day`).
4. **Re-logging sleep the same day edits, never duplicates.** → test in Task 7 (`re-logging sleep today edits the same entry`).
5. **Screen reader path never depends on the park:** the drawer's rows log everything the objects do. → test in Task 5 (`every kind of care can be logged from the drawer`).

## Stage 1: the park and the drawer

### Task 1: Park layout (pure)

**Files:** Create `src/domain/park/layout.ts`; Test `__tests__/parkLayout.test.ts`

**Interfaces:**
- Produces:
  - `type ParkObject = 'river' | 'tree' | 'flowerbed' | 'hammock' | 'path'`
  - `interface Rect { x: number; y: number; w: number; h: number }` (screen points, relative to the world's top-left)
  - `interface ParkLayout { worldW: number; worldH: number; objects: Record<ParkObject, Rect>; startX: number }`
  - `parkLayout(screenW: number, screenH: number): ParkLayout`
  - `PARALLAX = { sky: 0.15, far: 0.35, mid: 0.6, world: 1 }` (fraction of foreground scroll each layer moves)
- Values: `worldW = round(screenW × 2.2)`, `worldH = screenH`. Object centres as fractions of world width/height: tree (0.20, 0.42), flowerbed (0.12, 0.78), river (0.42, 0.62), path (0.62, 0.82), hammock (0.80, 0.50). Each rect at least 44×44 pt and at most 0.3 × screenW wide. `startX` = scroll offset that centres the tree-and-river view (0.12 × worldW, clamped to [0, worldW − screenW]).
